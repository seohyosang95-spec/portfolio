# 서효상 포트폴리오 앱 · FIELD NOTES

취업용으로 기존 포트폴리오를 다시 구성한 설치 가능한 정적 사이트입니다. 이번 버전은 흔한 자기소개 랜딩 페이지 대신, 실제 보안 실습의 허용·거부 기록과 개인 작업 습관이 보이는 `FIELD NOTES / CASEBOOK` 방향으로 디자인했습니다. 포트폴리오 화면과 편집실이 한 폴더에 들어 있어, 내용을 바꾸고 바로 확인할 수 있습니다.

## 이번 개편에 반영한 내용

- 첫 화면을 자기소개 중심에서 정보보안 직무·작업 방식·프로젝트 결과 중심으로 재구성
- 논문, 프롬프트 체크메이트 앱, 접근 제어 API 실습, 기록 기반 포트폴리오를 프로젝트 카드로 통합
- 완료·구현/검증 진행·경험 정리·완성 후 업데이트 상태를 분리
- 프로젝트 필터(전체 / 보안 / 제품·분석 / 팀프로젝트) 추가
- 팀프로젝트가 완성되면 프로젝트명·기간·내 역할·기술·결과·링크만 채울 수 있는 슬롯 추가
- 보안관제·솔루션 엔지니어 가이드의 실무 흐름(수집→판정→대응→보고→개선)과 채용공고 분석 단계를 포트폴리오 구조에 반영
- 아직 수행하지 않은 홈랩 SOC·SIEM·ATT&CK 실습은 완료 경험으로 표시하지 않고 다음 보강 항목으로 분리
- 이력서·자기소개서·경력기술서·논문 PDF 다운로드 유지
- 브라우저에서 설치할 수 있는 PWA 매니페스트와 오프라인 캐시 추가
- `editor.html`에서 소개·프로젝트·팀프로젝트 내용을 수정하고 브라우저에 저장
- 편집 내용을 JSON으로 내보내거나 다시 불러오는 기능 추가
- 세로 작업 레일, 관찰 로그, 요청 결과, 기록 타임라인을 사용한 개인 작업 노트형 화면

## 로컬 실행

설치 버튼과 서비스 워커는 `file://` 주소보다 로컬 서버에서 안정적으로 동작합니다. 아래처럼 실행합니다.

```powershell
python -m http.server 4173
```

이후 `http://localhost:4173/`를 열고, 첫 화면의 `앱으로 설치` 버튼 또는 브라우저 메뉴의 `설치`를 선택합니다. 내용 수정은 `http://localhost:4173/editor.html`에서 합니다.

편집 내용은 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기에서도 이어서 쓰려면 편집실의 `내용 내보내기`로 JSON을 보관한 뒤 `JSON 불러오기`를 사용합니다. 원본 문구와 구조는 이 폴더의 HTML·JS 파일에 남아 있으므로, 정식 업데이트가 필요할 때는 원본 파일도 함께 수정합니다.

## 팀프로젝트 추가 시 필요한 자료

1. 프로젝트명과 기간
2. 해결하려던 문제와 대상 사용자
3. 내가 맡은 기능과 실제 기여
4. 사용 기술
5. 협업 방식과 어려웠던 점
6. 완성 결과, 검증 방법, 공개 링크

자료를 받으면 팀프로젝트 슬롯을 완료 카드로 바꾸고, 필요하면 지원 문서의 프로젝트 항목도 함께 맞춥니다.
